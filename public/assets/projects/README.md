# Project Images Directory (`/public/assets/projects/`)

You can customize or replace any project thumbnail or sub-project image by replacing the corresponding image file in this directory:

### Image File Naming Convention:

#### Main Projects:
- `ecommerce-main.jpg` — Enterprise eCommerce Platform
- `vehicle-reservation.jpg` — Vehicle Reservation System
- `resource-mgmt.jpg` — Resource Management System
- `iot-monitoring.jpg` — IoT Monitoring Platform
- `butwal-cricket.jpg` — Butwal Cricket Platform
- `wordpress-main.jpg` — Custom WordPress & WooCommerce Engine

#### eCommerce Sub-Projects:
- `sub-japanese-marketplace.jpg` — Japanese Multi-Vendor B2B & B2C Marketplace
- `sub-subscription-portal.jpg` — Subscription & Recurring Membership Portal
- `sub-flash-sale.jpg` — High-Volume Flash Sale & Coupon Storefront
- `sub-affiliate-engine.jpg` — Affiliate & Multi-Tier Commission Engine

#### WordPress Sub-Projects:
- `sub-woo-booking.jpg` — WooCommerce Customizer & Booking Storefront
- `sub-b2b-wholesale.jpg` — Multilingual B2B Wholesale Product Catalog

### How to update an image:
Simply paste your image (JPG, PNG, or WebP) into `/public/assets/projects/` with the exact filename listed above.
The website will automatically display your updated image!
